# Joint worker, target and current-authority recovery

Nineteen selected cases combine actual fresh LangGraph SQLite workers with a
real protected HTTP target process restart. Current host grant, issuer policy,
service key, store identity and clock selection precede dispatch or cached-result
release. Earlier signed effects remain authentic after recovery permission ends.

The additive installed reader and publication gate preserve historical profiles.
Keys, clocks and filesystems are author-operated; outside adoption and independent
custody are not established. [Profile, matrix and commands](PROFILE.md) explain
the native processes, source pins, semantic controls and retained originals.

The producing operation is run by the operator's runtime; the packet it wrote is
retained under [retained](retained), with its producer sources withheld by digest.
Run the profile's tests and `python verify_retained.py` to replay it.
