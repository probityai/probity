# ADK user responses

Use the [installed routing reference](../interop/adk-user-responses-2026-10-04/README.md)
to check a confirmed or long-running tool response across agent turns. It pins
Google's October 4 routing fix, keeps the exact issuing call and sub-agent,
checks that later plain text returns to the root, and retains actual callbacks
beside the signed file effects.

Approval, task text, tool execution, host completion and publication have
separate records. An offline installed reader reconstructs all three finite
cases and verifies the actual Observer packet. The producer and witness remain
author-operated PEER work; outside custody and recurring host adoption need
their own decisions and runs.
