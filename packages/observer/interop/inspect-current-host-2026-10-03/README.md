# Installed Inspect 0.3.276 consumer

This separate extension runs six declared mock tool, agent and local workload
cases against Inspect 0.3.276. It installs a new reader wheel separately from the
native framework and repeats the resulting consumer decision. Inspect 0.3.273,
its original reader, profile, scores and retained records remain unchanged.

The selected upstream tag `0.3.276` and current main both pointed to
`93f7182cf2ce9be22724b05e499cd1358d7ed41d` when qualified. Installation and runtime
metadata must report exactly 0.3.276. This profile does not accept future versions.

The trusted bootstrap freezes the exact six-case population, adapter and legacy
source, normally installed wheel hashes, all 26 Observer Python module hashes,
and all 834 current Inspect Python source Gitblob identities before any model
call. It removes inherited provider credentials and Python/pip configuration,
refuses unselected package bytecode caches, and launches isolated children with
`-I -B`. The reader environment contains neither Inspect nor provider SDKs.

The three shared grammar files retain their original immutable bytes. Their
digests are checked before their retained buffers are compiled. The new adapter
uses a separate namespace with literal `probity-inspect-execution-v2` and 0.3.276
selectors; the original files continue to declare v1 and 0.3.273. Full adapter
source and version mapping are added to retained configuration source. Eight
legacy selected task/solver/tool/mock/rubric source files are unchanged across
0.3.273 to 0.3.276; the pre-run full native source population also selects the
changed model, buffer, reconstruction, provider and sandbox files. The finite
mock profile exercises the supported native call/log path, and supplies no
general assurance about those other provider or sandbox behaviors.

After execution the bootstrap independently reads original native JSON bytes,
their native run/evaluation IDs, captured declaration and source files. It checks
their joins and creates external consumer pins without using producer convenience
pins. The installed reader runs twice and must return byte-identical decisions.
Six fresh mutations of native bytes, bindings, plan, history, configuration and
declaration must each be refused. Child stdout, stderr, exits and timeouts are
retained. Artifacts include original native JSON, source selection, policies,
both wheels, repeated decisions and refusal records for 90 days.

Expected measured population: 6 planned, 5 started, 4 complete/scored, 3 task
passes, 1 task failure, 1 harness error and 1 declared unstarted case. Error and
unstarted entries remain separate. Mock token counts are not normalized model
resources. A local OPEN-to-DONE readback supplies no independent effect custody.
This is same-operator captured-byte reconstruction, not an authenticated witness,
real-model benchmark, producer acceptance or recurring outside adoption.

Installation uses the workflow's fixed Python 3.12.14, uv 0.12.19, setuptools
81.0.0 and wheel 0.46.3 selections with reproducible wheel timestamps. Native
dependencies come from the selected upstream `uv.lock`, with the explicitly
selected Observer crypto/runtime and build-tool overlay; its exact tagged source
is then normally installed. Existing Observer source is separately checked out
at `62f5d0c6fbd785259db2d5c8076dd844b53a0593` and normally installed. Both owned candidate and immutable reader checkout use the canonical public
`probityai/agent-evidence-observer` origin, with exact commit and tree identities
retained independently of package names.

```sh
PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 python -B -m pytest -q -c /dev/null test_bootstrap.py
```

The CI runs on owned changes, protected merge checks and manual dispatch. A green
owned run is an implementation result. The Inspect listing PR #5665 remains
separate and unchanged. A technical Inspect core change requires the producer's
accepted-issue route; this extension does not bypass it or claim upstream adoption.
