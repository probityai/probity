# Verifier downloads

The verifier was published on PyPI as `probity-verify` and is now published as `agent-evidence-verify`. PyPI has no way to rename a project, so each name keeps its own count. The downloads badge in the README is the sum of both.

|---|--:|---|
| [`probity-verify`](https://pypi.org/project/probity-verify/) | 10,003 (fixed) | [pepy.tech/projects/probity-verify](https://pepy.tech/projects/probity-verify) |
| [`agent-evidence-verify`](https://pypi.org/project/agent-evidence-verify/) | 3,218 | [pepy.tech/projects/agent-evidence-verify](https://pepy.tech/projects/agent-evidence-verify) |
| **Total** | **13,221** | sum of the rows above |

`probity-verify` is fixed at its pepy API total read at 2026-11-08 16:44 UTC, just before its last release made it install the new name; counting it live after that would count each of those installs twice.

Read from the pepy.tech API (`api.pepy.tech/api/v2/projects/<name>`, all-time totals) at 2026-11-09 12:02 UTC. This page and the badge are written by the same scheduled run ([scripts/refresh-badges.py](../scripts/refresh-badges.py)), so they always show the same numbers.

Install the current name: `pip install agent-evidence-verify`.
